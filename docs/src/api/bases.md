# [Bases](@id Bases)

Spectral bases define the function spaces used to represent fields. Dedalus supports one-dimensional bases (Fourier, Chebyshev, Jacobi), two-dimensional curvilinear bases (disk, annulus, sphere), and three-dimensional bases (shell, ball).
